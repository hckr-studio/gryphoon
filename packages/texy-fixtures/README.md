# @gryphoon/texy-fixtures

Oracle fixtures shared by the Texy ports ([@gryphoon/texy](../texy),
[the Clojure port](../texy-clj)). Generated by the oracle tools of the
texy reference repository (`tools/` there — `GRYPHOON` points them at this
monorepo); regenerate there after an upstream change and run the port
suites here.

| Path | Consumers | Generated by |
| --- | --- | --- |
| `sources/` — the `.texy` inputs (upstream `tests/Texy/sources`) | both | copied from the reference repo |
| `parse/`, `passed/` — parse-phase / post-transform AST dumps | Node.js | `php-oracle.php --generate`, `transform-oracle.php --passed`; the `*-on` variants are single-source runs with `--emoticon` (e.g. `php-oracle.php --emoticon tests/Texy/sources/emoticon.texy > parse/emoticon-on.txt`) |
| `render/`, `render-full/`, `text/` — rendered HTML / plain text | Node.js (render-full also Clojure) | `transform-oracle.php --render --emoticon`, `--render-full --emoticon`, `--text --emoticon`; copy the `emoticon.html`/`.txt` result over the `-on` variant |
| `render-typo/`, `render-typo-flat/` — typography on, no emoticons except the `-on` variant | Node.js (render-typo), Clojure (render-typo-flat) | `transform-oracle.php --render-typo` / `--render-typo-flat` (plain), plus a `--emoticon` run whose `emoticon.html` becomes `emoticon-on.html` |
| `render-flat/` — the Clojure port's flat-format set, no emoticons | Clojure | `transform-oracle.php --render-flat` |
| `hyphenation-corpus.json`, `typo-probe.json`, `wordwrap-corpus.json` — differential corpora | both | `hyphenation-probe.php`, `typo-probe.php`, `wordwrap-oracle.php` |
| `regexp-corpus.json`, `configurator-corpus.json` — Node.js-only corpora | Node.js | `regexp-corpus.php`, `configurator-probe.php` |
